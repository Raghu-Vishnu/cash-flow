Know where your money goes

Create an account (for example "HDFC Savings") and upload its statements as CSV, Excel or PDF. Every file is checked against the account number and its running balance, so nothing goes missing or lands in the wrong place.

infoWhere to get your statement

  • Net banking: Accounts → Statement → pick a date range → download as Excel / CSV (most reliable) or PDF.
  • Password-protected PDFs are supported. You'll be asked for the password, which is usually set by your bank (for example name + date of birth).
  • Account Aggregator apps (such as Fold, INDmoney or Jupiter) can usually export transactions as CSV, which you can upload here.

troubleshootStatement diagnostics

Something missing or wrong after an import? Create an anonymised report of a statement to share for troubleshooting. Names, account, reference and phone numbers, UPI IDs and birth dates are replaced; dates and amounts are kept. It runs on this device only, and nothing is imported or uploaded.

cloudGoogle Drive backup

Save a backup to your own Google Drive, then restore it on any phone or computer. The file goes straight from this browser to your Drive: Cash Flow has no server and never sees your data. The app can only see the backup file it creates, not the rest of your Drive.

backupYour data

Everything is stored only in this browser on this device. Back up regularly, because clearing browser data deletes it. Use backup & restore to move your data to another device.
